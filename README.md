## Overview
Expense Tracker (CN) is a minimalist, single-file web application designed for users who value privacy and simplicity. It allows you to log expenses, categorize them, and visualize your spending habits through an integrated dashboard—all without needing a database or backend server. Everything is stored securely in your browser's local storage.

## Features
*   **Categorized Tracking**: Organize expenses by custom categories (Food, Transport, Entertainment, etc.).
*   **Monthly Summary**: Quick-view cards to monitor your budget performance for the current month.
*   **Data Visualization**: Built-in, zero-dependency CSS/JS bar chart to visualize spending trends.
*   **Privacy-First**: No tracking, no login, and no cloud syncing; all data stays on your device via `localStorage`.
*   **Responsive Design**: Modern UI built with Flexbox and Grid, optimized for both mobile and desktop.

## Localization Notes
*   **Language**: Specifically tailored for Simplified Chinese (zh-CN) users.
*   **Format**: Date and currency formatting (CNY/¥) follow standard mainland China conventions.
*   **Directionality**: Optimized for LTR (Left-to-Right) layout.

## Tech Stack
*   **Frontend**: HTML5, Modern CSS (Flexbox/Grid), Vanilla JavaScript (ES6+).
*   **Storage**: Browser LocalStorage.
*   **Deployment**: GitHub Pages (Static hosting).
